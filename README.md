# Media Downloader 📱

> YouTube, TikTok, Instagram, Facebook, Twitter/X, Terabox সহ ১০০০+ সাইট থেকে ভিডিও ও অডিও ডাউনলোড করুন।

## ✨ ফিচার

- 🎬 **ভিডিও ডাউনলোড** — 144p থেকে 1080p পর্যন্ত
- 🎵 **অডিও ডাউনলোড** — শুধু গান/অডিও
- 📋 **ডাউনলোড কিউ** — একসাথে একাধিক ডাউনলোড
- 📁 **ফাইল ম্যানেজার** — ডাউনলোড করা ফাইল দেখুন
- 🔗 **শেয়ার ইন্টেন্ট** — যেকোনো অ্যাপ থেকে লিংক শেয়ার করুন
- 🌙 **ডার্ক মোড** সাপোর্ট

## 📥 APK ডাউনলোড

[**Releases পেজ**](../../releases) থেকে সর্বশেষ APK ডাউনলোড করুন।

- `app-arm64-v8a-release.apk` → নতুন ফোন (সুপারিশকৃত)
- `app-armeabi-v7a-release.apk` → পুরনো ফোন
- `app-release.apk` → Universal

## 🛠️ Build করুন

```bash
# Flutter ইনস্টল করুন
git clone https://github.com/flutter/flutter.git

# প্রজেক্ট ক্লোন করুন
git clone https://github.com/sajjadhossan/media-downloader.git
cd media-downloader

# ডিপেন্ডেন্সি ইনস্টল করুন
flutter pub get

# APK বিল্ড করুন
flutter build apk --release
```
